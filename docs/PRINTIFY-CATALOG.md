| Feature | Available | Notes |
|---------|-----------|-------|
| **Custom label** | ✅ Yes | Full-wrap label printing on most products |
| **Custom design** | ✅ Yes | Your artwork printed on candle label |
| **Engraving** | ✅ Yes | Available on select products (Lument Engraving) |
| **Vessel color** | ⚠️ Limited | Some products offer 3-5 color options |
| **Scent choice** | ✅ Yes | Pre-scented candles with multiple scent options |
| **Wax type** | ❌ No | Fixed by provider |
| **Wick type** | ❌ No | Fixed by provider |

### Label Design Guidelines

- **Label area:** Varies by product — check each product's mockup generator
- **Wrap style:** Full wrap label or front label depending on vessel
- **Text:**
  - Product name
  - Brand name
  - Scent description
  - Burn time
  - Weight
  - Ingredients
- **Graphics:**
  - Your brand logo
  - Custom illustrations
  - Color schemes

### Engraving (Lument products)

- Available on select Lument candles
- Can engrave text or simple designs on glass
- Not suitable for complex artwork

## Image Requirements

### Label Design Specifications

| Specification | Requirement |
|--------------|-------------|
| **Format** | PNG (preferred), JPG, SVG |
| **Resolution** | 300 DPI (minimum) |
| **Color Space** | RGB (sRGB recommended) |
| **Dimensions** | Product-specific — check each product's print area in mockup generator |
| **Max File Size** | ~100MB (varies by provider) |
| **Bleed** | Check product-specific requirements |
| **Background** | Transparent or solid color |

### How to Get Exact Dimensions

1. Go to printify.com → select a candle product
2. Open the mockup generator/editor
3. Check the "Design Guidelines" or "Print Area" section
4. Each product has its own exact dimensions

### Best Practices

- Use high-resolution images (minimum 300 DPI)
- Avoid tiny text that may not print clearly
- Use bold colors for visibility on candle labels
- Test with print mockup before publishing
- Consider how the label looks on the actual candle shape

### Order Flow

3. Printify manufactures/pours candle (2-5 days)
4. Candle ships to customer

## Appendix: Printify API

### Product Creation API

- **Endpoint:** `POST /v1/shops/{shop_id}/products.json`
- **Capabilities:** Create products, add images, set variants, manage inventory
- **Documentation:** https://docs.printify.com/
- **Authentication:** Bearer token (API key)

### Order Management API

- **Endpoint:** `POST /v1/shops/{shop_id}/orders.json`
- **Capabilities:** Submit orders, track status, manage fulfillment
- **Webhooks:** Available for order status updates

### Integration Tips

- Use the API to auto-submit orders when customers purchase
- Map your product variants to Printify variants
- Set up webhook for order status tracking
- Consider using Printify's mockup generator for product images
